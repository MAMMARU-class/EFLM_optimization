## 原因となる式

共通のばね則 `Fs(ds)`、質量、床反力の波形、胴体運動の積分方法は同じである。違うのは、ばね伸びから脚の位置と力の伝達率を求める幾何である。

- [approxの評価式](../elastic_approx/sim_cycle_elastic_approx.m) は、`ds=0` で作った関数 `l(k), f(k), g(k)` を用い、脚長を `l(k)−f(k)ds`、角度補正を `g(k)ds` とする。足先の真の閉路と各導関数の `ds` 依存を一次近似している。
- [exactの評価式](../elastic_exact/sim_cycle_elastic_exact.m) は、現在の `ds` における真の脚長 `R(k,ds)` と角度 `β(k,ds)` を使い、`R−r=0`、`Fs+Fr·R_ds+τr·β_ds=0` を同時に解く。関節角、角速度、関節トルクもその場の幾何微分から計算する。

exactの解では伸びが最大13.7 mmに達する。これは下腿リンク自然長135 mmの約10%、機構寸法 `LB=30 mm` の約46%であり、`ds=0` 周りの一次近似の誤差が無視できるとはいえない。交差評価で同じ入力でも最大伸びがほぼ2倍になること、approxの真の足先位置が最大2 mm超ずれることが、その影響を直接示している。この幾何差が膝角と関節の仕事率を変え、制約上で選べる最適化変数も変える。

両モデルとも `MultiStart` の探索結果であり、大域最適性は保証されない。壁時計時間はapprox約655秒、exact約496秒だったが、評価回数や失敗候補数（約7,486件対13,334件）も違うため、この2回だけから「exactの1評価が速い」とは結論できない。また、`valid=1` は密な1201点と設定した許容誤差での判定であり、連続時間の全時刻を数学的に保証するものではない。
