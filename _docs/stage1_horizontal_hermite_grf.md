# 水平床反力の区分3次Hermite表現

`stage1_point_mass` の水平床反力を `Fx(t)=A f(t)` とする。鉛直床反力と立脚時間倍率の定義は従来どおり。

## 実行時の設定

`run_stage1_optimization.m` で以下を設定する。

```matlab
overrides.grfN = 7;              % 等間隔制御点数 n（1回の実行では固定、4以上）
overrides.grfSlope = [-45 45 0];  % 全自由傾きの [下限, 上限, 基準値]、単位 s^-1
overrides.AmpH = [5 35 10];      % 振幅 A の [下限, 上限, 初期値]、単位 N
```

傾きは角度ではなく、物理時間に対する `df/dt`。`grfN` は最適化する整数ではなく実行設定。
`k=2,...,n-2`、`j∈{2,...,n-1}\{k}` の `(n-3)^2` 組合せを探索する。
広域段階の `starts` は組合せ全体への総数であり、少なくとも `(n-3)^2` が必要。
各組合せへ均等に開始点を割り当て、固定した k,j に対して既存の並列MultiStartを行う。
広域探索で最も良い実行可能候補の組合せを選び、狭域MultiStartと密な軌道での修正を行う。
実行可能候補がない場合は違反量の小さい候補を選ぶ。連続変数の格子探索は行わない。
大域最適性の保証はない。

## 傾きの初期値

各 `(k,j)` の決定後、各開始点の符号付き制御点値 `f_i` と、その開始点の立脚時間から

\[
b_1^{init}=b_n^{init}=0,\qquad
b_i^{init}=\frac{f_{i+1}-f_{i-1}}{2\Delta t}\quad(2\le i\le n-1,\ i\ne j),
\qquad b_j^{init}=0
\]

を計算する。自由な傾きの初期値だけを探索上下限に収める。狭域探索で0が
傾きの上下限外にある場合、端点の初期値も最も近い境界値に収める。
`grfSlope` の第3要素は基準値として保持するが、通常のMultiStart開始点ではこの自動計算を優先する。
立脚時間が不正で計算できない開始点では元の傾きを保持し、実行不可能として扱う。
`a` の値や探索範囲を、隣接点の直線の傾きによって制限することはない。

広域探索の全開始点へ適用する。狭域探索では広域の最良解をそのまま1番目の開始点に残し、
残りの開始点に適用する。このとき傾きは狭域の上下限内に収める。

初期曲線の符号・振幅・力積は解析式で確認し、広域の各組合せの表示に
`shape/impulse-feasible seeds` として条件を満たす開始点数を示す。
この表示は脚の幾何やモータ制約を含む実行可能性の判定ではない。
条件を満たさない開始点も捨てず、SQPの制約によって修正する。
初期傾きの変更だけで力積ゼロを保証することはなく、傾きが最適化中に固定されるわけでもない。
計算は開始点群をまとめた配列演算で行い、脚のシミュレーションは呼ばない。

## 変数の配置

既存の `[A, thetaL, vx0, Duty, r0, stanceScale]` に、自由な値の比率 `n-4` 個、自由傾き `n-1` 個を追加。
床反力形状だけでは連続 `2n-4` 個（Aを含む）、整数2個、全体では連続 `2n+1` 個となる。

- `t_i=(i-1)Ts/(n-1)`、開始・終了・k点の値は0。
- j点の絶対値を1とし、j点の傾きを0とする。
- その他の内部点の比率は `1e-4 <= a_i <= 1-1e-4`。kより前は負、後は正。
- 比率は `[1,k,j,n]` を除く点番号の昇順、傾きはj以外の点番号の昇順に格納。
- `A>=0` とし、全軌道の振幅上限とj点から最大絶対床反力がAとなる。

## 積分と運動生成

区間幅を `h=Ts/(n-1)`、局所座標を `u=(t-ti)/h` とする。各区間は

\[
f=c_3u^3+c_2u^2+c_1u+c_0,
\quad c_3=2f_i-2f_{i+1}+h(b_i+b_{i+1}),
\]
\[
c_2=-3f_i+3f_{i+1}-h(2b_i+b_{i+1}),\quad c_1=hb_i,\quad c_0=f_i.
\]

1区間の積分は `h(fi+fi+1)/2+h²(bi-bi+1)/12`。
等間隔なので内部点の傾き項は相殺され、両端の値が0なら

\[
I=\int_0^{T_s}f(t)\,dt
=h\sum_{i=2}^{n-1}f_i+\frac{h^2}{12}(b_1-b_n).
\]

提示された式の右辺は **I/h** に相当する。ゼロ条件は同じである。
不等間隔では内部傾きの相殺は一般に成立しない。
最適化へは無次元等式 `I/Ts=0` を渡す。

\[
v_x(t)=v_{x0}+\frac{A}{m}\int_0^tf(\tau)d\tau,\qquad
x(t)=x_0+v_{x0}t+\frac{A}{m}\int_0^t(t-\tau)f(\tau)d\tau.
\]

区間ごとの1回積分・2回積分を多項式から厳密に計算し、時刻に応じて評価する。
数値ODE積分や台形積分で胴体軌道を生成しない。`dFx/dt` も解析微分。
試行候補が力積制約を満たさない場合も、その力積を実際の速度へ反映し、等式制約で不適格とする。
許容誤差 `tol` に対する水平速度の周期誤差上限は `A Ts tol / m`。

## 形状制約

各区間で導関数の2次方程式を解き、端点および区間内部の全極値を評価する。
これにより時刻サンプリングで見逃し得る符号反転と `|f|>1` を調べる。
区間の正しい符号を `d=-1 (i<k), +1 (i>=k)` とし、以下を課す。

- 両端は `d f >=0`。内部の制御点は比率の下限で0から離す。
- 区間内部の極値は `d f >=1e-4` とし、0に接する余分な接点も除く。
- 端点・全極値で `|f|<=1`。
- 各区間の符号付き平均値 `d integral(f)/h >=1e-4` とし、全区間0を除く。

厳密な開不等式は数値最適化で直接扱えないため、上記の微小マージンとソルバー許容誤差を用いる。
このマージンは数学的な `f>0` よりわずかに強い制限となる。
既存の摩擦円錐・モータ・関節角・ばね伸び制約も適用。
摩擦円錐などは従来どおり時間評価点で判定し、密な軌道でも最終判定する。

## 保存

`result.mat` に最終解の多項式係数・制御点・k,jを保存する。
`report.txt` にk,j、制御点の値・傾き、水平力積を記載する。
制御点時刻は `horizontal_grf_control_points.csv` に保存する。
中間候補や全組合せの詳細は保存しない。
`result.mat` は最終結果の確定時に1回だけ保存し、評価履歴CSV・中間チェックポイント・詳細な実行ログは生成しない。
`horizontal_grf_control_points.csv`、`horizontal_grf_shape_constraints.csv`、
`horizontal_grf_summary.csv` から形状と制約残差を確認できる。
