# elastic_approx実装と実行記録

## 構成

- `common/parameters`: 旧モデル由来の物理定数、最適化設定。
- `common/function`: 床反力の解析積分、予圧ばね構成則、関節軸TN制約。
- `common/optimization`: 広域MultiStart、狭域MultiStart、高密度制約再検査。
- `common/out`: MAT/CSV出力、グラフ、EFLM形状のMP4と保存結果からの再生成。
- `elastic_approx/kinematics`: 四節リンク形状と一次感度、事前計算テーブル。
- `elastic_approx/sim_cycle_elastic_approx.m`: 並進運動と代数的なばね釣り合い、関節速度・トルク評価。
- `elastic_approx/main_elastic_approx.m`: MATLAB R2026b用実行入口。

`rigid`、`elastic_exact`、旧プロジェクトは編集しない。

## 計算方法

今回の総質量質点・規定床反力モデルでは、並進加速度が時刻の既知関数なので解析積分する。DAE全体を汎用時間積分器へ渡さず、微分部分を解析的に消去して残る幾何・ばね釣り合いを解く。これは動力学の省略ではなく、指定モデルの分離解法である。

関節角速度はばね釣り合いと幾何式の時間微分から求める。立脚期の絶対関節仕事だけをCoTに使う。総質量は1.93741375 kg、減衰はゼロ。

広域探索の初期範囲は振幅0--20 N、接地角3--25度、速度0.15--2.5 m/s、Duty 0.45--0.90。今回の実行許可に基づく有限探索範囲であり、モデル全体の物理的限界ではない。MultiStartは大域最適性を保証しないため、探索境界への接近も保存して評価する。

## 検出して修正した事項

1. 予圧立ち上がり部分でNewton法が反復上限に達したため、残差に基づくバックトラックを追加した。単一歩容検証では約0.08秒で収束し、幾何残差は約1e-17 m、力残差は約1e-12 N以下。
2. 基準脚長0.277 mでは接地角3度でも股関節角が54.57度となり55度下限に違反した。基準脚長を0.300 mへ修正した。
3. 新しい初期候補 `[2.5 N, 5度, 0.8 m/s, 0.8]` は1201点の診断で最大制約違反ゼロ、平均速度約0.7893 m/s、CoT約0.0949。これは最適化結果ではない。
4. R2026b Update 1は起動できるが、Optimization ToolboxおよびGlobal Optimization Toolbox本体が未導入。ライセンスは確認できても `optimoptions` を実行できず、MultiStart試行を停止した。R2026aのToolboxは混用しない。

## 保存と検証

保存先は `_logs/elastic_approx/<日時>/`。最適化時はソースのスナップショット、物理定数、設定、乱数状態、開始点、探索履歴、最終高密度軌道、エネルギー、制約、代数残差を保存する。

診断用軌道は `diagnostic_result.mat` として保存し、最適化済みと区別する。動画中の遊脚姿勢は可視化用補間で、胴体のみ弾道計算。一次近似軌道と厳密閉リンク描画の足先位置の差も保存する。

Toolbox導入後に `validate_elastic_approx`、続けて `main_elastic_approx` を実行する。高密度軌道の制約違反が残る場合は追加の狭域修正を行い、それでも満たせない結果には有効フラグを付けない。
