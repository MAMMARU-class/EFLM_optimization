# elastic_approx実装と実行記録

## 構成

- `common/parameters`: 旧モデル由来の物理定数、最適化設定。
- `common/function`: 床反力の解析積分、予圧ばね構成則、関節軸TN制約。
- `common/optimization`: 広域MultiStart、狭域MultiStart、高密度制約再検査。
- `common/out`: MAT/CSV出力、グラフ、EFLM形状のMP4と保存結果からの再生成。
- `elastic_approx/kinematics`: 四節リンク形状と一次感度、事前計算テーブル。
- `elastic_approx/sim_cycle_elastic_approx.m`: 並進運動と代数的なばね釣り合い、関節速度・トルク評価。
- `elastic_approx/main_elastic_approx.m`: MATLAB R2026b用実行入口。

`rigid`、`elastic_exact`、旧プロジェクトは編集しない。

## 計算方法

今回の総質量質点・規定床反力モデルでは、並進加速度が時刻の既知関数なので解析積分する。DAE全体を汎用時間積分器へ渡さず、微分部分を解析的に消去して残る幾何・ばね釣り合いを解く。これは動力学の省略ではなく、指定モデルの分離解法である。

関節角速度はばね釣り合いと幾何式の時間微分から求める。立脚期の絶対関節仕事だけをCoTに使う。総質量は1.93741375 kg、減衰はゼロ。

最新の広域探索範囲は振幅0--50 N、接地角0.5--35度、速度0.03--2 m/s、Duty 0.10--0.90。立脚・遊脚それぞれ0.2秒以上を不等式制約として追加した。今回の実行許可に基づく有限探索範囲であり、モデル全体の物理的限界ではない。MultiStartは大域最適性を保証しないため、探索境界への接近も保存して評価する。

## 検出して修正した事項

1. 予圧立ち上がり部分でNewton法が反復上限に達したため、残差に基づくバックトラックを追加した。単一歩容検証では約0.08秒で収束し、幾何残差は約1e-17 m、力残差は約1e-12 N以下。
2. 基準脚長0.277 mでは接地角3度でも股関節角が54.57度となり55度下限に違反した。基準脚長を0.300 mへ修正した。
3. 新しい初期候補 `[2.5 N, 5度, 0.8 m/s, 0.8]` は1201点の診断で最大制約違反ゼロ、平均速度約0.7893 m/s、CoT約0.0949。これは最適化結果ではない。
4. R2026b Update 1は起動できたが、Optimization ToolboxおよびGlobal Optimization Toolbox本体が未導入だった。ユーザー承認後、MathWorks公式MPMからR2026bへ追加し、`fmincon` と `MultiStart` の実行を確認した。
5. 当初の探索は速度2.5 m/s・Duty 0.9の上限に達したため、一度速度20 m/s・Duty 0.999まで拡大した。その後、ユーザー指定の両期間0.2秒以上を追加したため、この短周期解は現在の条件では無効である。
6. 全時刻の制約を直接渡したSQPが遅かったため実行を停止した。広域・狭域探索では制約種類別の最大違反に集約し、最終段階では制約の厳しい個別時刻を選択して追加する方式へ変更した。
7. 予圧境界の解像度を上げるため、時刻点を接地・離陸付近へ集中させた。関節速度は解析的な陰関数微分で評価し、時間差分との整合性と仮想仕事の恒等式を検証した。
8. 両期間0.2秒以上の条件下で初期姿勢を成立させるため、基準脚長を0.340 mへ調整した。リンク寸法は旧モデルのまま。単なる速度低下では立脚中の沈み込みが増えるため、失敗時は検証済みの初期候補を保持する。

## 保存と検証

保存先は `_logs/elastic_approx/<日時>/`。最適化時はソースのスナップショット、物理定数、設定、乱数状態、開始点、探索履歴、最終高密度軌道、エネルギー、制約、代数残差を保存する。

プロジェクト直下の `run_elastic_approx_optimization.m` を標準実行入口とする。引数の構造体で探索上下限、初期値、MultiStart開始点数などを上書きできる。各実行には `report.txt` を保存し、呼び出し元、広域・狭域・最終修正の経路、段階別の開始点数・成功数・SQP反復数・関数評価数・所要時間、最終結果を記録する。動画フォルダへの描画コードの重複コピーはやめ、ソースは `source/` に集約する。

R2026b Update 1の現インストールでは、`fmincon` の通常SQPが内部関数 `nlpSQP` の欠落により実行できない。利用可能であることを確認した `sqp-legacy` を既定の局所解法とし、`optimization_settings.m` の `algorithm` で明示する。

診断用軌道は `diagnostic_result.mat` として保存し、最適化済みと区別する。動画中の遊脚は胴体のみ描画し、脚は表示しない。計算座標を変えずに描画のX軸を反転して左進行とする。剛体リンクは黒、ばねリンクは青いジグザグ。一次近似軌道と厳密閉リンク描画の足先位置の差も保存する。

`validate_elastic_approx`、続けて `main_elastic_approx` を実行する。高密度軌道の制約違反が残る場合は追加の狭域修正を行い、それでも満たせない結果には有効フラグを付けない。
