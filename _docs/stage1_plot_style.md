# stage1 の立脚期グラフ出力

`stage1_point_mass` の最適化が保存する `plots/stance.png` と `plots/stance.fig` の描画設定を記録する。実装は [`common/out/save_run_outputs.m`](../common/out/save_run_outputs.m) にある。見た目の基準は `_logs/test/20261105_161428_342` の比較画像である。

| 項目 | 設定 |
|---|---|
| 図の大きさ | 1500 × 1125 px、白背景 |
| 配置 | 3 行 × 2 列、タイル間と外周の余白は `compact` |
| データ線 | 2 pt |
| 軸線 | 1.5 pt |
| 軸目盛り・ラベル・凡例 | 25 pt（従来の標準的な 10 pt に対して 2.5 倍） |
| PNG 書き出し | `exportgraphics`、220 dpi |
| 編集用データ | 同じ図を `stance.fig` に保存 |

6 面の順序は、位置、床反力、関節角、関節トルク、ばね伸び、関節パワーとする。ばね伸びの縦軸には、余白内に収めるため変数記号 `d_s [mm]` を使う。横軸はすべて時刻で、横軸ラベルは最下段に表示する。各軸の縦範囲は、その実行結果のデータから MATLAB が決める。基準画像のような**複数モデル間で共通の縦軸範囲**は、stage1 単独の出力には適用しない。

軸目盛りには `TickLabelInterpreter='latex'` を設定し、軸ラベルと凡例にも `Interpreter='latex'` を指定する。文字列は `$...$` で囲み、変数を数式の斜体、単位と説明語を `\mathrm{...}` の立体で表示する。例えば水平床反力は `$F_x$`、時間軸は `$\mathrm{time}\;[\mathrm{s}]$` とする。MATLAB の `latex` インタープリターによる組版なので、外部の TeX コンパイラを呼び出す構成ではない。図中文字の書体と数式表記を TeX に近づけるための設定である。

既存の `_logs` 内の画像は変更しない。この設定は次回以降の stage1 の結果保存時に生成するグラフへ適用する。
